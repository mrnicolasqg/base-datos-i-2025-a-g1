¿Qué es ETL (Extraer, Transformar y Cargar)?
ETL es un proceso que ayuda a mover datos de diferentes fuentes a una base de datos central o almacén de datos. Se compone de tres pasos:

Extraer: Se recopilan datos de múltiples fuentes (como bases de datos, archivos, APIs, etc.).
Transformar: Se limpian, organizan y convierten los datos en un formato útil y consistente.
Cargar: Se almacenan los datos en una base de datos de destino, lista para análisis.
Este proceso es clave para la inteligencia de negocios, el análisis de datos y el aprendizaje automático, ya que permite trabajar con datos limpios y estructurados.
