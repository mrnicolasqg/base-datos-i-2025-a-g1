Modulo-05 la ciencia de datos es un deporte de equipo
El equipo del proyecto de ciencia de datos

Cada uno de estos roles tiene funciones clave en un proyecto de ciencia de datos:

Analista de datos: Se enfoca en explorar los datos, visualizarlos y generar informes para responder preguntas comerciales. 
Científico de datos: Diseña modelos predictivos, experimenta con algoritmos de machine learning y extrae insights complejos.
Ingeniero de datos: Construye y mantiene la infraestructura para almacenar, procesar y mover datos de manera eficiente.
