Modulo 2: Big Data

Que es Big data

Big Data es un montón de datos, pero en cantidades enormes. Es tanta información que no se puede manejar con herramientas normales, así que se usan tecnologías especiales para procesarla y analizarla. Se usa en cosas como redes sociales, compras en línea o hasta en la salud para encontrar patrones y tomar mejores decisiones.

Los 5 Vads

Los elementos de big data se pueden explicar utilizando cinco características amplias llamadas 5 Vatios. Los 5 Vs son:
Volumen: Se trata de la enorme cantidad de datos generados cada segundo.
Velocidad: La rapidez con la que los datos se crean, procesan y analizan.
Variedad: Diferentes tipos de datos (estructurados, no estructurados, semiestructurados).
Veracidad: La calidad y confiabilidad de los datos.
Valor: La utilidad de los datos para tomar decisiones o generar beneficios.
