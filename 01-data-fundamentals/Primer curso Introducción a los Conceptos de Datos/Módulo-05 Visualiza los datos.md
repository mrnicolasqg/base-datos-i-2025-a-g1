Módulo 5: Visualiza los datos
Tipos de visualizaciones
Los analistas de datos utilizan diferentes tipos de gráficos para representar información de manera clara y comprensible. La elección del gráfico depende del tipo de datos:
 Datos cuantitativos se usan gráficos como:

Gráficos de barras: Comparan cantidades entre categorías.
Gráficos de líneas: Muestran tendencias a lo largo del tiempo.
Histogramas: Representan la distribución de datos numéricos.
Datos cualitativos se representan con:

Gráficos de sectores: Muestran proporciones de un todo.
Diagramas de dispersión: Relacionan dos variables categóricas.
 Gráficos conceptuales: Ayudan a organizar ideas y relaciones:
Mapas conceptuales: Representan estructuras y conexiones.
Infografías: Combinan imágenes y datos para contar una historia.
