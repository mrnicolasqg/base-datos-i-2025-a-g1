En el mundo del análisis de datos lo que busca una empresa tanto en el analista de datos como en el científico de datos son las siguientes características.

Para los analistas de datos, es fundamental dominar:
•	Lenguajes de consulta como SQL para extraer datos de bases de datos.
•	Hojas de cálculo como Excel o Google Sheets para organizar y analizar datos.
•	Visualización de datos con herramientas como Tableau, Power BI o Matplotlib.
•	Estadística descriptiva e inferencial para interpretar datos correctamente.

Para los científicos de datos, el enfoque es más técnico y avanzado:

•	Programación en Python o R, ya que son esenciales para modelado y análisis.
•	Aprendizaje automático o Machine Learning con bibliotecas como Scikit-learn o TensorFlow.
•	Big Data y herramientas como Apache Spark para manejar grandes volúmenes de información.
•	Análisis de datos no estructurados, como texto o imágenes, con NLP o visión por computadora.

Características útiles
para ser un analista o cientifico de datos hay que tener en cuenta caracteristicas que pueden ayudar para hacer un mejor trabajo como lo es la curiosidad ya que te permitirá explorar datos con una mentalidad analítica y descubrir patrones ocultos. También es importante tener confianza en tus hallazgos, pero al mismo tiempo ser flexible y estar dispuesto a cambiar de enfoque si los datos muestran algo diferente.
