Herramientas populares:
Microsoft Excel: Manejo de datos, generación de gráficos y análisis con funciones y macros.
Hojas de Google: Similar a Excel, pero en la nube, permitiendo colaboración en tiempo real.
SQL (Lenguaje de Consulta Estructurada): Recuperación y manipulación de datos en bases de datos relacionales.

IBM Watson Studio: Plataforma para análisis avanzado con inteligencia artificial y machine learning.
Matplotlib: Librería de Python para generar gráficos personalizados.
