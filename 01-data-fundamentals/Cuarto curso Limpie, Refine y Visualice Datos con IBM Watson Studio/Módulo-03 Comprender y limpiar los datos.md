En este módulo 03, nos muestran cómo comprender y limpiar los datos dentro de IBM Watson Studio utilizando la herramienta de refinería de datos. La limpieza de datos es un paso clave para asegurar que los resultados sean precisos y útiles, eliminando información irrelevante o "ruidosa" y conservando solo los datos importantes para el análisis.

El proceso sigue una serie de pasos estructurados:

•	Exploración del conjunto de datos para identificar qué información es útil y qué no.
•	Eliminación de datos innecesarios que podrían afectar la calidad del análisis.
•	Transformación y normalización de datos para que sean más consistentes.
•	Visualización de datos para verificar patrones y posibles errores.
•	Optimización del conjunto de datos asegurando que los datos finales sean relevantes para el objetivo del proyecto.
